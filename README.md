# Bible Fun Run

A side-scrolling runner game with a biblical theme, developed using HTML5, CSS, and JavaScript. The player controls Noah as he runs and jumps over obstacles while Bible verses are displayed.

## Game Description

Bible Fun Run is a simple endless runner game where the player character (Noah) must jump over obstacles to avoid collisions. The game features:

- Side-scrolling gameplay with increasing difficulty
- Character animation and obstacle variety
- Score tracking and high score system
- Bible verse display that changes with each play session
- Sound effects with toggle option
- Mobile and desktop compatibility

## How to Play

- **Desktop**: Press the spacebar to jump
- **Mobile**: Tap the screen to jump
- Avoid obstacles by jumping over them
- Collect power-ups (rare green items) for bonuses
- Press 'S' to toggle sound on/off
- Click on the menu area to return to the main menu

## Technical Details

This game was built using:
- HTML5 Canvas for rendering
- JavaScript for game logic
- CSS for styling
- LocalStorage for saving high scores and game settings
- PhoneGap for mobile packaging and deployment

## Installation

### Web Version
1. Clone the repository
2. Open index.html in a web browser

### Mobile Version (using PhoneGap)
1. Clone the repository
2. Use PhoneGap CLI or PhoneGap Desktop app to serve the project
3. Connect with the PhoneGap mobile app or build for your target platform
